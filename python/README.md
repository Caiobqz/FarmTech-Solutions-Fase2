# Python — Ir Além (opcional)

Esta pasta será usada para a integração com uma API meteorológica pública.

## Objetivo

Criar um programa em Python que consulte dados meteorológicos úteis para a decisão de irrigação, como chuva atual ou previsão de chuva.

## O que o grupo deve decidir

- qual API será utilizada;
- qual dado será relevante para a irrigação;
- como o resultado será apresentado;
- como essa informação chegará ao ESP32.

## Formas aceitas pela atividade

A integração pode ser:

- automática, caso o grupo consiga implementar;
- manual, copiando o resultado obtido em Python para uma variável do ESP32;
- via Monitor Serial, explorando entrada de caracteres no ESP32.

## Resultado esperado

Ao final, deverá existir aqui um arquivo Python documentado e simples de executar, além da explicação correspondente no README principal.

> A solução não foi implementada antecipadamente para preservar a etapa prática de aprendizagem do grupo.
