# Dados do projeto

Esta pasta poderá armazenar arquivos utilizados pela análise em R ou pelos testes da Fase 2.

## Estrutura sugerida para um CSV de leituras

Caso o grupo decida registrar dados, uma tabela pode conter colunas como:

- `timestamp`;
- `umidade`;
- `ph_simulado`;
- `n`;
- `p`;
- `k`;
- `irrigacao`;
- `chuva_prevista`.

Essas colunas são apenas uma sugestão de organização. O grupo deve registrar somente informações realmente utilizadas no projeto.

## Regra

Não adicionar dados fictícios como se fossem resultados reais de testes. Se forem dados simulados, isso deve ficar explicitamente identificado.
