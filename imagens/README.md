# Imagens da documentação

As três capturas finais já foram selecionadas durante a validação do projeto e devem ser versionadas nesta pasta com estes nomes:

- `circuito-wokwi.png` — visão completa do circuito com ESP32, botões N/P/K, LDR, DHT22 e relé;
- `irrigacao-ligada.png` — circuito + Monitor Serial com umidade em aproximadamente 35%, `CHUVA=NAO` e `RELE: ON -> BOMBA LIGADA`;
- `irrigacao-desligada.png` — circuito + Monitor Serial com umidade em aproximadamente 35%, `CHUVA=SIM` e `RELE: OFF -> BOMBA DESLIGADA`.

O README principal já referencia esses três caminhos. Portanto, depois que os PNGs forem enviados para esta pasta, as imagens serão exibidas automaticamente.

## Cuidados

- manter os nomes acima exatamente;
- não substituir as capturas reais por imagens genéricas;
- evitar recortes que escondam componentes ou o resultado do Monitor Serial;
- não alterar o repositório depois da entrega final na plataforma FIAP.
