# R — Ir Além (opcional)

Esta pasta será usada para uma análise estatística relacionada à irrigação.

## Objetivo

Usar R para analisar dados do projeto e produzir uma informação que possa ajudar na decisão de ligar ou não a irrigação.

## Ideias de dados

- umidade;
- pH simulado;
- número de acionamentos da bomba;
- condição de chuva;
- histórico de leituras.

## Exemplos de análises possíveis

- média da umidade;
- desvio padrão;
- média do pH simulado;
- quantidade ou proporção de acionamentos da irrigação;
- comparação entre períodos mais secos e mais úmidos.

## Resultado esperado

Ao final, deverá existir aqui um script em R e uma breve explicação, no README principal, de como a análise ajuda a interpretar o comportamento do sistema.

> A implementação foi deixada em aberto para que o grupo desenvolva a solução e compreenda o que está sendo calculado.
