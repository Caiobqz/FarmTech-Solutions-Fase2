# Como contribuir com o projeto

Este repositório será desenvolvido em grupo. Para que o histórico do Git reflita o trabalho real de cada integrante, cada pessoa deve fazer seus próprios commits sempre que possível.

## Fluxo sugerido

1. Atualize sua cópia local antes de começar.
2. Trabalhe em uma tarefa pequena e bem definida.
3. Teste sua alteração.
4. Faça um commit com mensagem clara.
5. Envie para o GitHub.
6. Avise o grupo sobre o que foi concluído.

## Exemplos de mensagens de commit

- `docs: adiciona pesquisa sobre pH do café`
- `wokwi: monta circuito inicial do ESP32`
- `esp32: adiciona leitura do sensor de umidade`
- `python: adiciona consulta meteorológica`
- `r: adiciona análise de umidade`
- `docs: adiciona imagens do circuito`

## Divisão inicial sugerida

A divisão abaixo é apenas uma sugestão e pode ser ajustada pelo grupo:

- Caio: organização, integração e apoio no ESP32;
- Suellen: pesquisa da cultura e documentação;

Todos devem compreender o funcionamento geral do projeto antes da entrega.

## Regra importante

Não inserir no código valores de pH, umidade ou critérios agrícolas sem registrar a fonte utilizada na documentação.
